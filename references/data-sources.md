# 数据来源与字段字典

所有金额在测算表中为**不含税、万元**口径；对外报价/合同额用含税口径（按实际税率换算，通常 ×1.06）。填入模板前先按"取值口径"核对。

> **本文件只讲口径，不写死任何具体数值。** 具体金额/客户名/站址一律以本次三份输入经 `scripts/extract_data.py` 抽取出的 `project_data.json` 为准，避免换项目时误用旧数据。

> **重要：输入文件命名不固定。** 三份输入可能被改名（如"附件X：…前评估测算表.xls""附件X：智联项目规范运维前置审核要点.xlsx""站址资源服务合同.doc"）。**按文件类型 + 内容关键词识别**，不要按固定文件名。命令行传中文路径易乱码，推荐在 Python 内用 `glob.glob('*前评估测算表.xls')` 解析后调用 `scripts/extract_data.py` 里的 `read_calc()/read_ops()/derive()`。

## 一、项目前评估测算表.xls

用 `xlrd` 读取（老式 .xls）。多个 sheet：效益分析表、现金流量表、测算结论、智联项目前评估管理审批单。

| 字段 | 取出位置/关键词 | 填入口径 |
|---|---|---|
| 项目名称 | 智联项目概况「项目名称」 | 项目全名，直接作文件名（格式：与<客户名>订立的<项目简称>） |
| 客户名称 | 概况「客户名称」 | 唯一客户；忽略合同残留的其他公司名 |
| 项目大类/子项 | 概况「项目大类」「项目子项」 | 决定 PPT 项目类型（须与测算表一致，勿沿用模板自带类型） |
| 合同年限/工期 | 概况「合同年限」「预计建设工期（月）」 | 服务期、建设期 |
| 预付比例 | 概况「首批预付款比例」 | 收款方式（常见 100% 预付） |
| 净额收入 | 测算结论「净额收入」 | 不含税收入 |
| 含税收入 | 现金流入 / 含税收入合计 | 合同额、对外报价 |
| 运行维护成本 | 运营成本「运行维护成本」 | 成本明细之一 |
| 电费 | 运营成本「电费」 | 成本明细之一 |
| 占用母公司资源应结算费用 | 运营成本同名行（按最低 300 元/站/年或净额收入 2%-4%） | 成本明细之一 |
| 运营成本合计 | 「运营成本合计」/「项目成本费用合计」 | 总成本 |
| 项目毛利润 | 测算结论「项目毛利润」 | 毛利 |
| 毛利率 | 「项目毛利率（含代垫资金回收）」 | 含两个毛利率口径 |
| 剔除塔租毛利率 | 「项目毛利率（剔除塔租收入）」 | 常与上行相同或相近 |
| 净现值 | 「财务净现值」 | 汇报材料效益页 |
| 投资合计 | 「项目投资合计」 | 为 0 时投资报酬率无法计算 |

**税率反推**：含税收入 / 不含税收入 − 1，取整数百分比，填入模板税率栏。

## 二、智联项目规范运维前置审核要点.xlsx

用 `openpyxl` 读（data_only=True）。关键行（以 D 列"审核要点"编号定位）：

| 编号 | 内容 | 用途 |
|---|---|---|
| D7 | 运维模式判定（如"一体代维"） | **决定 PPT 第11页维护服务必须实填**（不是"不涉及"） |
| D8/D9 | 共享巡检单价与频次 | 维护费组成 |
| D14 | 不上塔维修单价（元/站/年） | 维护费组成 |

**维护费算式（重要）**：
- 元/站/年（不含税）= 共享巡检单价 × 次数/年 + 不上塔维修单价
- 该数须与测算表"运行维护成本"对平（注意单位换算：元 ↔ 万元）。
- 含税包干价（万元/站/年）= 不含税元数 × (1+税率) ÷ 10000。
- 匹配维修单价时须按"元/站"匹配，避开"元/次"的历史报价干扰。

若 D7 不是一体代维，则按实际模式调整单价项；巡检次数、是否上塔以 D8/D14 与合同为准。

## 三、站址资源服务合同.doc

老式二进制 .doc，`python-docx` 读不了。按 `technical-notes.md` 用编辑器 SDK 导出 HTML 再清洗，或 COM 读取。补充字段：

| 字段 | 说明 |
|---|---|
| 站址名称/编码 | 以合同正文为准 |
| 站址位置 | 以合同正文为准 |
| 客户 | 以测算表为准；合同若并列出现其他公司名，多为模板残留，须剔除 |
| 服务期 | 以合同正文为准（可能与协议有效期不同） |
| 工期 | 以合同正文为准 |
| 付款 | 预付比例、收票后付款时限 |
| 设备 | 型号/数量/重量/功耗/甲供自装等，以合同正文为准 |
| 维护 | 运维模式、是否上塔、巡检频次、修复时限、资产归属、电费分摊方式 |
| 招标 | 直签或公开招标 |
| 后项采购 | 无后项采购时 PPT 相关分项填"不涉及" |

## 派生字段速查（由 extract_data.py 动态生成）

以下字段由 `scripts/extract_data.py` 输出到 `project_data.json`，校验器 `verify_outputs.py` 以此为数值基准。具体值每次运行都以本次输入为准：

| 派生项 | JSON 字段 | 来源 |
|---|---|---|
| 客户全名/简称 | `client` / `client_short` | 测算表 + 项目名正则 |
| 项目简称 | `project_short` | 项目名正则 |
| 含税/不含税/税率 | `income_with_tax` / `income_net` / `tax_rate` | 测算表（税率反推） |
| 成本明细 | `cost_maintain` / `cost_electric` / `cost_parent_res` | 测算表运营成本区 |
| 毛利/毛利率 | `profit` / `gross_margin_pct` | 测算表 |
| 维护费（不含税元/站/年） | `maintain_yuan_per_site_year` | D9 + D14 算式 |
| 维护费（不含税/含税万元） | `maintain_wan_ex_tax` / `maintain_wan_with_tax` | 上行换算 |

> `project_data.json` 含本次真实项目数据，**不得提交到 git 仓库**（已在 .gitignore 中排除）；它只作为本地校验基准使用。
